# Piro Family — свадебные спецэффекты

Сайт Романа Аксенова / Piro Family для невест, организаторов и координаторов в Нижнем Новгороде. Новая версия создана на основе HTML, предоставленного владельцем: используются его контактные ссылки, фото, видео и история Ромы и Насти.

## Открыть сайт

Распакуйте **весь** ZIP и откройте `index.html`. Рядом должны оставаться `style.css`, `effects.js`, `app.js` и папка `assets`.

Локальные CSS и JavaScript работают без сервера. Для загрузки внешних фото, видео и Google Fonts требуется интернет. При отсутствии сети остаются системные шрифты и фоновые заглушки. Отправка через системное меню/буфер зависит от браузера; сохранение TXT работает отдельно.

Для разработки: Node.js 22+, `npm start` (порт 3000, можно изменить через `PORT`). Установка npm-пакетов и сборка не нужны. Проверка синтаксиса: `npm run check`.

Можно разместить index.html, style.css, effects.js, app.js и assets на любом статическом HTTPS-хостинге, в том числе в подпапке: ссылки на локальные ресурсы относительные.

## Что реализовано

- Фотографический первый экран, лёгкая декоративная анимация и поддержка reduced motion.
- Три момента свадьбы, подробный раздел тяжёлого дыма.
- 13 услуг с фильтрами, ценами, составом, длительностью, описанием процесса и ограничениями в модальных окнах.
- Четыре реальных видео по исходным ссылкам; загрузка начинается при открытии видео. Закрытие останавливает плеер.
- Три пакетных сценария и квиз из четырёх шагов: моменты → эффекты → детали → результат.
- Автоматическая сумма выбранных эффектов, проверка пустого выбора, предупреждение о превышении выбранного бюджета, изменение состава.
- Подготовленное сообщение в Telegram, скачивание сценария в TXT, системная отправка или копирование при поддержке браузером.
- О команде, исходные изображения отзывов, блок для event-команд, FAQ, телефон и Telegram.
- Мобильное меню, нижняя панель действий, клавиатурное закрытие модальных окон, обработка ошибок медиа.

## Где менять информацию

- **Цены, состав, длительность, описания:** `effects.js`. Это предложенные для согласования ориентиры, а не подтверждённый прайс. При изменении цен обновите также статические цены в hero-карточках, разделе танца и пакетах в `index.html`.
- **Пакеты:** `index.html`, атрибуты `data-bundle` с ID эффектов. Квиз считает сумму цен из `effects.js`; скидки не заявлены.
- **Телефон и Telegram:** `index.html`, `app.js`. Взяты из присланного HTML: +7 (999) 075-41-24, https://t.me/pyro_family.
- **Фото:** https://cvetnoydym.ru/111/1.jpg (дневной салют), 2.jpg (дым), 3.jpg (фонтаны), otz/9.jpeg (Рома и Настя).
- **Видео:** https://cvetnoydym.ru/111/1.mp4, 2.mp4, 3.mp4, 4.mp4; соответствие заголовкам сохранено из исходного сайта.
- **Отзывы:** оригинальные изображения otz/1.jpg, otz/2.jpg, otz/3.jpg. Тексты и оценки не придумывались.
- Для эффектов без подтверждённого фото используются декоративные символы. Сторонние картинки товаров и Pinterest из исходника не выдаются за портфолио команды.

## Данные и бронирование

Сервера заявок нет. Квиз хранит данные только в оперативной памяти страницы. Telegram-ссылка содержит составленный текст, который пользователь отправляет самостоятельно. Бронирование, проверка даты, договор и оплата происходят при личном общении. Аналитика и собственные cookies не установлены. Есть пояснение по данным, сторонним медиа и Telegram в футере.

## Проверки и ограничения

Проверены в Chromium: каталог, фильтры, модальные окна, квиз, суммы и пакетные сценарии, валидация, безопасное отображение введённого текста, текст Telegram, содержимое скачанного файла, мобильное меню и отсутствие горизонтального переполнения на ширинах 360/390/768 px. Учитывается reduced motion.

В текущей облачной среде внешний медиахост cvetnoydym.ru блокируется сетевым шлюзом (403), поэтому доступность самих изображений и воспроизведение видео отсюда не подтверждены. Проверены обработка ошибки и соответствие URL пользовательскому исходнику. Перед публичным запуском проверьте медиа из обычного браузера. Прямую file:// навигацию также блокирует политика облачного браузера; соответствие относительных путей файлам проверяется отдельно.

Перед публикацией подтвердите цены и состав, условия выезда и бронирования, права на публикацию материалов; укажите конечный canonical/og:url после выбора домена. Данные ИП из исходника не перенесены, так как имя в реквизитах расходится с именем владельца.
