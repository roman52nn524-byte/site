# Piro Family

Адаптивный сайт спецэффектов Романа Аксенова, Нижний Новгород. HTML, CSS и JavaScript без сборки и внешних runtime-зависимостей.

## Запуск

Node.js 22 или новее: `npm start`. Сервер слушает порт 3000, переменная `PORT` позволяет выбрать другой. `npm run check` проверяет синтаксис JavaScript. Можно разместить index.html, style.css, app.js и assets на любом статическом HTTPS-хостинге.

## Возможности

Интерактивная иллюстрация салюта с поддержкой reduced motion, 13 эффектов с фильтрами, четыре сценария свадьбы, сохранение сценария в TXT, отправка через системное меню или буфер обмена, адаптивная вёрстка и FAQ.

## Перед публикацией

- Контактный переход ведёт на предоставленный владельцем магазин https://pyro-family.ru/. Прямые телефон и мессенджеры пока не добавлены: магазин недоступен из текущей среды (403 от сетевого шлюза).
- Графика — иллюстрации, не реальные фотографии выполненных работ. Замените или дополните её согласованными фотографиями и видео Piro Family.
- Уточните название услуги «пиротехнические огни» и тексты сценариев с владельцем.
- Добавьте конечный домен, canonical, og:url и реальное og:image после выбора адреса публикации.
- Отправки заявки на сервер нет. Сохранение сценария не бронирует дату; пользователь связывается с компанией через магазин.
- Google Fonts необязательны: при недоступности используются системные шрифты.

Каждая облачная задача уже изолирована: используйте существующий checkout, не создавайте worktree без явного запроса.
